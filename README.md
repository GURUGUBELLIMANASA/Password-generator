# Password Generator 🔐

A simple command-line password generator built with Python.

This project generates random passwords based on user-defined criteria such as password length and character types including letters, numbers, and symbols.

## Features

- Generate random passwords
- User chooses password length
- Option to include:
  - Letters (A-Z, a-z)
  - Numbers (0-9)
  - Symbols (!@#$%^&*)

## Technologies Used

- Python
- random module
- string module
